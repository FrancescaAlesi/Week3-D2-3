# Week3-D2
Settimana 3 giorno 2


La pagina web deve gestire ed organizzare le mie task giornaliere.
Il progetto fornisce già la realizzazione di un HTML5 e CSS3, il mio intervento è focalizzato sullo sviluppo dell'intero JavaScript, gestendo: 
- creazione;
- modifiche;
- eliminazione;
- analisi,
dei task tramite la manipolazione del DOM. 

Il codice JavaScript deve soddisfare le seguenti consegne:

1. Aggiungi task:
   - Aggiungere tutte le task di cui abbiamo bisogno. 

2. Elimina task:
   - Aggiungere un pulsante "Elimina" per ogni singola task
   - Il pulsante momentaneamente non deve funzionare ma deve diventare blu al passaggio del cursore. 

3. Data ed ora :
   - Aggiungere la data corrente della creazione della task, nel formato (GG/MM/AAAA), utilizzando `Date`.
   - Aggiungere l'ora corrente, nel formato (HH:MM:SS). 

4. Evidenzia / togli evidenza:
   - Evidenziare la task che stiamo svolgendo. 
   - Rimuovere l'evidenziazione e metterlo nella task successiva. 

5. Conta per priorità:
   - Dobbiamo aggiungere un Totale che ad ogni task aggiunta o rimossa si aggiorni in modo automatico.
